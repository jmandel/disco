# DECISIONS — disco v4

One line each. Adding an option, predicate, command, file or concept requires deleting one and a line here.
`test/budget.test.ts` enforces the counts. Every feature request is answered first with "which primitive's OUTPUT changes?".

## Shape (frozen as v4.0 on 2026-09-01; later lines are fold-backs within the rules)

- **v4 from v2.** Engine kept (CDP attach, no page instrumentation, always-on SQLite recorder). API, predicate DSL and 5-file pack replaced. Why: every stranger round added a predicate nuance; the agent should write Playwright and the report should carry the evidence.
- **Three verbs**: `look`, `act`, `sql` (+ `body`, `json`), plus `waitFor` and `reached`. Nothing wraps what Playwright or SQL already do.
- **`act` is a bracket around the agent's code.** One budget, `max`: the default timeout of every Playwright call inside `run` and `until`, and the longest the act observes. Bare acts return on quiet: no request/response/frame/console/dialog/nav, no DOM change, no request this act started still unanswered; third-party sites count for none of it. `returned` and `pending` say what happened. No verdict.
- **The report proposes untils** (responses with `+ms`; roles that appeared with their new state; the one that left, if unique; the url path and the `nav` event; storage; page text through shadow roots, never a fragment already on screen; an `<option>` as attached). Each was false before the action, must hold 400 ms after it, and must be on-canvas, or it is not printed. Text proposals say they hold only until the text changes.
- **`alreadyTrue` is generic**: any until that resolved before dispatch. The refusal says the action ran; a note describes the target's state now; a failed response wait lists what answered in the 5 s before the act; the next act lists app requests that landed unattributed since the previous one.
- **Diagnoses** parse the locator out of Playwright's message and hit-test it: not-found (candidates that paste; a text selector naming an aria-label is pointed at the control), hidden, disabled, occluded (a styled control is named as such), offscreen, unclickable, detached, timeout, error (Node-vs-page hint). A click that landed but blocked past max counts, with a note.
- **`look`** renders numbered marks in a scratch page (never in the app's page), full page ≤ 4000 px, document coordinates; names controls as the accessibility tree does; durable selector = data-test, stable id, unique `role=[name]` (exact; else an anchored whitespace-tolerant regex), `[name]`/`[placeholder]`, else a css path; lists anchors without href, tabindex/onclick/draggable targets, test-id value elements, walks open shadow roots; marks off-canvas (left of, above, right of the page) and unnamed dialogs; `look(selector)` reports visibility, what is under the pointer, and ARIA state; the text folds a table's repeated controls.
- **`open`** navigates as its own act and returns when quiet; prefers the page it drove before (CDP target id), then the url, then a page no popup opened; writes `apps/.current`, which `close` keeps because the log outlives the browser.
- **One recorder per browser** (claimed in browser.json; silent joiners stamp windows; takeover when the recorder is gone). A request still unanswered at close gets a second, then is marked `error`, never left `pending`.
- **Storage** via `context.cookies()` (HttpOnly visible) + localStorage + sessionStorage; **downloads** via CDP; screenshots are `<hash>.jpg`; every act keeps its post-state aria as a blob (`report.aria`).
- **`json`** prefers a path-boundary match and the collection over an item, waits 1 s for a body or a matching request still in flight, and **throws** when nothing matched (naming what did), when a query fragment spans several endpoints, or when the newest match answered ≥ 400.
- **`sql --json`** has one shape: rows with JSON text cells parsed. `sql` errors name the columns. `until.value` keeps JSON (≤ 2 KB) and describes Playwright objects; the report prints it.
- **Pack = `README.md` + `sdk.ts`** (+ gitignored `store/`, + `evidence/`). `sdk.ts` exports workflows, `anchors`-style constants and `check(s)`, runs its own check under `import.meta.main` (stopping at the first failure), and leaves the browser up. Write workflows take the record's fields; the check supplies DISCOTEST-marked values and reads only what it created.
- **Every `close` copies each cited act into `evidence/` as shapes, never values** (URL templates, body skeletons, blanked storage, no headers, no shots, `<data>` for any string that is a value in the app's JSON bodies or looks like an identifier/date/email/token; the aria tree keeps control names and blanks text). It names cites with no report, numbers a cited act's evidence lacks, uncited numbers, unbacked absolutes, sentences with no cite or sdk symbol, data that leaked into README.md or sdk.ts, and the store's size. Ranges cap at 10 acts. A cite always resolves to the committed file; the store is local and ephemeral. Trade accepted: "the body says X" is re-proved by the check, not by evidence. (Josh, 2026-09-02)
- **Shaping details settled on real stores (2026-09-02):** values are string leaves of the run's JSON API bodies (newest-first across runs, 2000 bodies); a value made only of words the app ships in its bundles or JSON keys is a label, except under name-like keys (name, display, given, family, text, identifier, comment…), which are data regardless ("nini" is a Swahili word in an OpenMRS bundle); the prose scan skips reference data (values in 5+ bodies) and single short words, and also covers the friction log beside the pack. Verified: two earlier OpenMRS packs re-shaped to 0 UUIDs, 0 known names, 29 chrome control names kept, 1 list name blanked.
- **RW2 judge (both packs PUBLISHABLE; Fable 9/9, 94 %; Opus 8/8, 84 %; unseen write task from each pack in 2 min):** `export const vocab = [...]` in sdk.ts is the pack's allowlist of app-defined labels — kept visible in evidence, not flagged in prose (both agents' top friction was "Vitals" blanked or nagged); truncated uuids and long opaque ids are blanked in text too. Value-level claims (a query parameter's value, a quoted UI string) stay unverifiable from shaped evidence by design; the check proves them.
- **`look(container)`** — one match that is a landmark-style container (main, form, section, dialog, table, fieldset, nav) returns the screen look scoped to it; menus, lists and divs stay matches so "is it visible?" keeps its answer. Why: every Opus log complained the app chrome repeats in every look (2d032c5).
- **`stats` is `scripts/stats.ts`**, dev-side; `_record` is an internal subcommand. **No `withApp`**.

## Rejected, and why

Server knobs leaking across sessions, the WS banner in every diff, app-fired POST reads under `writes`, a redirect 3 s after quiet, a user-identity reminder (app-specific or verdicts — the log has the facts); long-poll attribution by start time (documented); folding diff lines that only change a number; mouse-only targets without a role in `look` (no handler is detectable without instrumentation); copying untils across acts and guessed column names (the report and the error already say so); a "wait for all bodies" helper, a `disco evidence` command, a CLI verb to call one pack workflow (`json` waits, `close` copies, a script is one line); `look` as a citable act (a look is a view; the act that produced the screen carries its aria); `stats` calling a run unclean when its check asserts failures on purpose.
